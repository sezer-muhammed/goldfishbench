# GoldfishBench paper

[Read the nine-page PDF](paper.pdf) or [download the standalone TeX source package](source.zip).
The article contains English and Turkish abstracts, seven model conditions,
three vector figures and ten cited references. IEEE conference format describes
typesetting; no conference acceptance is claimed.

Author: Muhammed Izzet Sezer, i@imsezer.com. No affiliation is invented.
No public arXiv identifier has been assigned. The author handles arXiv submission
and has reported that endorsement is pending. Dataset release v1.0.0 is not an
arXiv version or a peer-review outcome.

The standalone package uses paper.tex with XeLaTeX / TeX Live2025. It includes
the compiled bibliography, IEEE class/style and the three active vector figures.
A clean local Tectonic0.17.0 build verified the same nine-page text/layout as the
reading PDF; actual arXiv server preview remains a separate step. No model
inference is needed to read or build the paper.

Dataset and measured scientific results are now available in this repository.
The paper's original table values, wording, nulls and technical exclusions are
unchanged. The historical648-pair endpoint is preserved separately inside
results/summary.json, alongside the post-hoc662-family analysis.
